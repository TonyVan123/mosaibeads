MOSAIBEADS 3.0 使用说明
=======================

1. 双击 MOSAIBEADS_v3.0.exe。
2. 点击右上角“打开图片”，选择照片、头像、宠物图或插画。
3. 左栏设置尺寸、品牌色板和传神程度；不希望智能调参改变的项目可勾选“固定”。
4. 点击顶部“智能调参（3 套）”，可切换“最传神 / 综合平衡 / 最易制作”。
   也可以直接点击“按当前参数生成”。
5. 如需严格限定手头已有的颜色，点击顶部“指定豆色”，在原图取样并确认色号。
6. 手工精修：
   - 在右侧色块调色板点击目标颜色；
   - 查看橙色边框和“当前”色号，确认选色；
   - 点击图纸格子填色，或按住左键拖动连续填色；
   - 下方色号与数量表会实时刷新，但不会把当前颜色重置；
   - Ctrl+Z 撤销，Ctrl+Y 重做。
7. 点击“导出图纸”，生成：
   - 豆孔成品预览 PNG
   - 纯像素图 PNG
   - 带色号高清图纸 PNG
   - 可打印 PDF
   - 用量清单 CSV
   - 工程数据 JSON

推荐起点：
- 单人头像/宠物：宽 48、24 色、抖动关闭
- 动漫/Logo：宽 32、12–18 色、杂色清理约 0.7
- 风景：宽 60、28 色、轻微抖动

注意：
- 第一次启动单文件 EXE 可能需要数秒解压组件。
- EXE 没有商业代码签名；若 SmartScreen 提示，请核对文件哈希和来源。
- 屏幕色板是近似值，正式作品建议用实体熨烫色卡校色。
- model_pack 已包含离线 AI 模型；GPU 安装包为可选项，失败会自动回退 CPU。
- V2.3.0 与 V3.0.0 放在不同版本目录和 GitHub Release 中，请勿混用文件。
