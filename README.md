# MOSAIBeads 3.0.1

**MOSAIC + AI + BEADS**：把照片、头像、宠物或插画转换成可直接制作的拼豆图纸，
在有限豆格和真实品牌色板中优先保留主体轮廓、五官和标志性特征。

## 直接使用

Windows 用户可直接运行 `MOSAIBeads_v3.0.1.exe`。程序默认完全离线处理图片。

源码运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

## V3 界面

- 左栏只保留 `1 · 尺寸与色板` 和 `2 · 传神程度`；
- `3 · 智能方案` 与 `4 · 预览与精修` 移到顶部；
- 顶部左侧只显示 `MOSAIBeads 3.0.1`，没有宣传副标题；
- 中央原图与图纸保持并排，顶部工具区为方形图片留出更合适的纵向比例；
- 右栏同时显示可点击的真实豆色色块，以及完整色号、名称和用量表。

### 用调色板填色

1. 在右侧调色板点击一种颜色；橙色边框和“当前”信息表示正在使用的豆色；
2. 点击图纸格子即可替换颜色，也可以按住左键连续拖动；
3. 当前选色在填色、数量刷新、撤销和重做后都保持不变；
4. 下方色号表实时更新每种豆色数量，也可点击表格行反向选择颜色；
5. `Ctrl+Z` 撤销，`Ctrl+Y` 重做。

## 全参数智能调参

“智能调参（3 套）”联合比较品牌色板、横向豆数、颜色预算、图片类型、透明背景和
全部传神参数。它先搜索空间填充候选，再用结构相似度、边缘保留、Lab 色差、孤立豆、
色块碎片度和可选 AI 语义特征选择 Pareto 前沿，给出：

- 最传神；
- 综合平衡；
- 最易制作。

每个生成参数旁都有“固定”复选框。勾选后，所有候选和最终方案都会严格保留该参数；
智能调参只搜索没有固定的项目。十项全部固定时程序会提示取消至少一项。

## 指定具体豆色

点击顶部“指定豆色”，再在原图取样。程序使用局部 Lab 中位色与 CIEDE2000 色差从
当前品牌色板推荐颜色。确认后的颜色是严格白名单，结果不会出现未选择的豆色。

## 可选 AI 模型

`model_pack/semantic_encoder.onnx` 是约 4MB 的 MobileNetV3-Small 特征编码器。
模型存在时可通过 OpenCV DNN 在 CPU 推理；运行 `model_pack/install_gpu_runtime.ps1`
可安装隔离的 CUDA 运行环境。任何 AI 运行失败都会自动回退，不影响普通转换。

## 推荐参数

| 场景 | 横向豆数 | 最多颜色 | 特征保护 | 杂色清理 | 抖动 |
|---|---:|---:|---:|---:|---|
| 单人头像 / 宠物 | 40–58 | 16–28 | 0.72–0.90 | 0.55–0.72 | 关闭 |
| 动漫 / Logo | 24–48 | 8–20 | 0.65–0.85 | 0.68–0.90 | 关闭 |
| 风景 / 建筑 | 48–80 | 20–36 | 0.55–0.75 | 0.35–0.60 | 轻微 |
| 多人照片 | 70 以上 | 24–40 | 0.80–0.95 | 0.40–0.60 | 关闭 |

29×29 是常见大板尺寸。5mm 豆下，48×48 图纸约为 24×24cm。

## 导出内容

“导出图纸”会生成：豆孔成品 PNG、纯像素 PNG、带色号高清 PNG、可打印 PDF、
用量 CSV 和可编辑 JSON 工程数据。导出目录默认以 `_MOSAIBeads` 结尾。

## 品牌色板

内置 MARD 291、Perler、Hama Midi 和 Artkal S 5mm。RGB 只用于屏幕近似显示，
重要作品应以实体、熨烫后的色卡最终校色。来源和许可见 `THIRD_PARTY_NOTICES.md`。

## 测试与打包

```powershell
python -m unittest discover -s tests -v
build_exe.bat
```

- `v2.3.0` 标签与 GitHub Release 保存最后一个 BeadSketch Studio 稳定版；
