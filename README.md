# BeadSketch Studio 2.3

把任意照片、头像、宠物或插画转换成可直接制作的拼豆图纸。核心目标不是普通的
“马赛克”，而是在有限豆格和真实颜色里优先保存主体轮廓、五官与标志性细节。

## 直接使用

如果目录中已有 `BeadSketchStudio_v2.3.exe` 或 `dist/BeadSketchStudio/BeadSketchStudio.exe`，
双击即可。程序完全离线处理图片。

源码运行：

```powershell
python -m pip install -r requirements.txt
python main.py
```

也可以双击 `run.bat`（本机需要已有 Python 和依赖）。

## V2 智能调参

打开图片后，可直接点击“全参数智能调参（3 套方案）”。程序把当前横向豆数与颜色数量作为搜索中心，
联合比较全部品牌色板、约 72%–128% 的横向豆数、约 60%–122% 的颜色预算、四种图片类型、
三种透明背景处理以及全部传神参数。它先在小尺寸预览中搜索至少 16 套空间填充组合，再根据结构相似度、
边缘保留、Lab 色差、孤立豆和色块碎片度选择 Pareto 前沿，最后只精算三个胜出方案：

- 最传神：允许使用更多豆格，优先五官、轮廓、明暗和颜色接近；
- 综合平衡：兼顾相似度与制作整洁度，默认推荐；
- 最易制作：同时考虑较小尺寸、较少颜色、连续色块和较少孤立豆。

方案下拉框可以即时切换；每次切换都会把左侧品牌、尺寸、颜色数、类型、背景和传神滑块同步为该方案的值。

### 固定部分参数

每个参与生成的参数右侧都有“固定”复选框。勾选后，联合搜索的每个候选和三套最终方案都会
严格保留该参数当前值；未勾选的参数仍正常搜索。例如固定品牌、横向豆数和颜色数量，就只比较
图片类型、背景和传神参数。若十项全部固定，程序会提示至少取消一项，不会重复计算相同结果。

## 指定具体豆色 Demo

点击“指定具体豆色 Demo”，再点击原图中的任意位置。程序会对局部 Lab 中位色和当前品牌
完整色板做 CIEDE2000 匹配，列出最接近的真实色号。逐个确认所需颜色后生成，结果使用的是
严格白名单：绝不会出现未选中的颜色。这个模式适合“我手头只有这些豆”或严格限定主题色。

## 可选 AI 模型包

`model_pack/semantic_encoder.onnx` 是 MobileNetV3-Small 视觉特征编码器，约 4MB。启用后，
智能调参在传统评分之外加入原图与候选图的高层特征余弦相似度。模型缺失或推理失败时会自动
回退到轻量视觉评分，不影响生成。

- 只有模型：通过 OpenCV DNN 在 CPU 本地推理；
- 运行 `model_pack/install_gpu_runtime.ps1`：创建独立环境并安装 CUDA 12/cuDNN，优先使用
  `CUDAExecutionProvider`；GPU 失败会回退 CPU；
- 图片和特征都不上传，不需要云端 API。

AI 只占总评分的一小部分，防止语义相似但边缘、色号或可制作性变差。

## 手动参数参考

| 场景 | 横向豆数 | 颜色 | 特征保护 | 杂色清理 | 抖动 |
|---|---:|---:|---:|---:|---|
| 单人头像 / 宠物 | 40–58 | 16–28 | 0.72–0.90 | 0.55–0.72 | 关闭 |
| 动漫 / Logo | 24–48 | 8–20 | 0.65–0.85 | 0.68–0.90 | 关闭 |
| 风景 / 建筑 | 48–80 | 20–36 | 0.55–0.75 | 0.35–0.60 | 轻微 |
| 多人照片 | 70 以上 | 24–40 | 0.80–0.95 | 0.40–0.60 | 关闭 |

29×29 是常见大板尺寸。5mm 豆下，48×48 的成品约为 24×24cm。

## 工作流

1. 打开图片后会按当前参数自动生成；
2. 按需要勾选各参数旁的“固定”，再点击“全参数智能调参（3 套方案）”；
3. 在右侧选中色号，点击图纸格子精修；
4. 导出会生成豆孔成品图、纯像素图、高清带色号图纸、PDF、用量 CSV 和 JSON 工程数据。

## 算法简介

程序综合使用结构感知 Lab 采样、显著性/边缘/人脸保护、有限品牌色板选择、
CIEDE2000 感知色差、边缘感知空间正则化和多目标搜索。可选 AI 模型增加视觉特征评分。
完整原理与调参方法见 `原理与调参指南.md`。

## 色板与颜色准确性

内置 MARD 291、Perler、Hama Midi 和 Artkal S 5mm。色板来自 MIT 许可的
BeadColors 数据库，详情见 `THIRD_PARTY_NOTICES.md`。屏幕 RGB 仅为近似值，正式作品
建议用实体熨烫色卡做最终校色。
